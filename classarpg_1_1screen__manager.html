Detailed Description

Stack of screens.

Change requests are queued and applied at the end of the frame: applying one during an update would destroy a screen while it is running.

◆ apply_pending()

void arpg::screen_manager::apply_pending ( )

Applies the queued requests.

Call once per frame, after update and render.

A request queued from within a request, such as an on_enter() pushing a transition, is handled on the next frame rather than in this pass.
