◆ level_shape

enum class arpg::level_shape : std::uint8_t
strong

How the rooms are laid out, which is what a biome chooses.

The shape decides how it looks; the topology it comes with decides how it plays. Both generators here grow a tree, so a level has no loop yet.

Enumerator
rigid 

Recursive splitting of one box.

Rooms are axis aligned and tightly packed: the architecture of something built by people, however mad.

organic 

Rooms accreted one against another, each attached to a wall of one already placed.

Irregular, but always made of actual rooms, which a bullet hell needs: an arena has to be readable at a glance.

◆ follow_camera()

vec2 arpg::follow_camera ( vec2  current,
vec2  target,
viewport_rect  room,
vec2  view,
float  dt,
float  stiffness 
)

Moves the view towards target and holds it over the room.

The view never shows anything outside room: the centre is held in by half a view, so the edge of the screen lands on the edge of the room rather than on the void beyond it. A room smaller than the view is centred instead, since holding it in would put the far limit before the near one.

Following is eased rather than snapped, which keeps the picture from juddering on every step of a fixed timestep. The easing is expressed through an exponential so it behaves the same whatever dt is: a plain lerp by a constant factor would follow faster on a machine that steps more often.

Parameters
currentwhere the view is now
targetwhat it is following, usually the player
viewsize of what is on screen, in room coordinates
stiffnesshow eagerly it catches up, in units per second. Larger is tighter; around ten feels attached without being rigid.

◆ apply_radial_deadzone()

vec2 arpg::apply_radial_deadzone ( vec2  stick,
float  inner,
float  outer = 1.0f 
)

Filters the resting noise out of an analog stick.

The magnitude of the stick is filtered, not each axis separately. Filtering per axis would let a diagonal through while rejecting the same magnitude on a single axis, and would clip the reachable directions into a square.

Below inner the result is zero; above outer it is a unit vector; in between the magnitude is rescaled linearly, so it starts from zero at the edge of the deadzone rather than jumping to inner.

Parameters
stickraw stick position, as reported by the device
innermagnitude under which the stick counts as resting
outermagnitude at which the stick counts as fully pushed

◆ asset_root()

std::filesystem::path arpg::asset_root ( std::string_view  from_command_line,
std::string_view  from_environment,
const std::filesystem::path &  beside_executable 
)

Where the game reads its data from.

The build mirrors assets next to the executable, and that copy is overwritten on the next build: tuning a figure there and then rebuilding would lose the work without saying so. Either source points the game at the working copy instead, so the file being edited live is the one under version control.

The command line wins over the environment, which wins over the copy beside the executable: what was typed for this run beats what a shell was left set to.

float  clearance 
)

Picks somewhere inside room to put a body of radius radius.

Keeps clearance away from every point of keep_clear, which is where the player sets foot and where the doorways are: arriving inside an enemy is not difficulty, it is a hit nobody could have avoided.

A small room ringed with doors may leave nowhere clear at all. Rather than fail, or loop, it gives up after a fixed number of tries and answers with the last spot it looked at: a wave quietly missing its enemies would be a worse bug than one standing a little too close.

Picks which archetypes to field for budget.

Spends greedily on what fits, so a rich room can afford the expensive archetypes while a corridor ends up with a handful of cheap ones. Draws from generator, so a seed replays the same room.

Returns
indices into catalogue, one per enemy to spawn. Composes a wave worth budget out of catalogue.

weights says how often each kind is offered, and is either empty, for an even draw, or as long as the catalogue. It is not the same lever as the cost: a brute costing eight parasites is already rare by the room it fills, but without a weight it is still offered as often as one.
