Detailed Description

Reads the backend and fills an input_snapshot.

The only place in the input path that knows a backend exists; everything downstream works on the snapshot alone.

Polls watched once, for the current rendered frame.

Only bound controls are polled, which avoids walking the hundreds of key codes the backend knows about. The mouse position lands in out already expressed in canvas pixels.
